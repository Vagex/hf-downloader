# 🎨 PromptReverser Studio - AI 图像反向工程与精准 Prompt 工作台

> 专业级 AI 图像反推系统，专为 **Midjourney v6.1 / Niji 6**、**FLUX.1 (Dev/Schnell)**、**Stable Diffusion XL / SD3**、**DALL-E 3**、**ComfyUI** 及 **可灵/LTX/Minimax AI 视频** 定制开发。

---

## ✨ 涵盖 7 大专业反推体系

本系统根据不同图像领域的特征，量身定制了 7 大专属反推模式与系统级提示词工程：

### 1. 🌟 通用图片反推（万能通用 · 所有图都能用）
- **反推核心**：主体、风格、色彩、光影、构图、质感、分辨率与微观细节描述。
- **解构维度**：视觉元素、色调、氛围、技法与关键词，中英双语输出，精准生成可直接绘制的 Prompt。

### 2. 🔤 字体 / Logo / 文字设计类（字形特征 · 质感特效 · 排版）
- **反推核心**：字体风格（现代/复古/赛博/手写/哥特）、粗细、衬线/无衬线、圆角倒角、3D 立体挤压、镜面光泽。
- **材质特效**：液态金属铬合金、磨砂亚克力、高透玻璃、霓虹发光、浮雕、渐变与描边。
- **排版分析**：Logo 构成比例、对齐方式、留白与视觉平衡。

### 3. 🏞️ 风景 / 场景类（自然景观 · 城市建筑 · 天气光影）
- **反推核心**：环境地貌、天气气候、时间时段（清晨/黄昏/蓝调/夜晚）、光线色温、氛围感、构图透视与景深。
- **要素解构**：天空云层（积雨云/朝霞）、植被、水体倒影、国家地理级风光大片镜头感。

### 4. 📷 摄影类（真人肖像 / 商业产品 / 纪实摄影）
- **反推核心**：相机型号（哈苏中画幅 / 索尼）、镜头焦距（85mm f/1.4 / 35mm）、光圈景深、光影布法（伦勃朗光 / 柔光箱 / 轮廓光）。
- **胶片与画质**：柯达 Portra 400 / 富士胶片色调、天然皮肤毛孔细腻质感、微量噪点颗粒与真实情绪。

### 5. 🎨 插画 / 二次元 / 治愈系（画风笔触 · 赛璐璐 · 厚涂国风）
- **反推核心**：手绘 / 板绘、平涂 / 半厚涂 / 水彩浸润、赛璐璐分层阴影、新海诚风 / 吉卜力治愈系。
- **线条色彩**：细腻勾线质感、马卡龙与低饱和莫兰迪配色、通透发光粒子与氛围感。

### 6. 🧊 3D 渲染 / C4D / Blender（Octane · PBR材质 · 三点布光）
- **反推核心**：C4D / Blender 建模风格、Octane / Redshift 物理光线追踪渲染、三点摄影棚布光、环境遮蔽（AO）与次表面散射（SSS）。
- **材质属性**：粗糙度（Roughness）、磨砂玻璃、电镀金属、黏土与微表面光泽。

### 7. 🧸 IP 角色 / 潮玩 / 盲盒（Q版潮玩 · 盲盒公仔 · 树脂PVC）
- **反推核心**：2头身/3头身 Q 版比例、大头萌系神态与大眼反光、潮流机能服饰与精致配件。
- **玩具触感**：哑光树脂、高光 PVC、植绒、半透果冻件、纯色展示底座与摄影棚柔光。

## 🚀 极速上手使用

### 方式 1：Windows 本地一键启动
1. 双击项目根目录下的 **`启动图片反推网站.bat`**。
2. 程序会自动检查依赖、启动后台服务器并为您自动在默认浏览器中打开 `http://localhost:3005`。
3. 若希望在后台无黑框静默运行，双击 `后台运行(无黑框).vbs` 即可。

### 方式 2：开发者模式 (Node.js)
```bash
cd image-prompt-reverser
npm install
npm run dev
```

## 🛠️ 多模态 Vision AI 接口支持

- **内置高精度智能仿真引擎**：无需任何 API Key，开箱即用，结合 HTML5 Canvas 实时提取的主色盘、画幅比与 7 大专业体系秒级输出高水准提示词。
- **OpenAI Vision 接口**：支持 `gpt-4o`、`gpt-4o-mini`。
- **Anthropic Claude 接口**：支持 `claude-3-5-sonnet`、`claude-3-haiku`。
- **Google Gemini 接口**：支持 `gemini-1.5-flash`、`gemini-2.0-flash`。
- **第三方中转 / OneAPI / Ollama 本地多模态**：支持自定义 Base URL 与 Model 自由对接。

## 📦 核心功能一览

- 🖼️ **多渠道图像载入**：支持本地拖拽、点击上传、系统截图快捷键直接粘贴 (`Ctrl + V`)。
- 🔍 **图像特征自动嗅探**：实时分析图像宽高、自动计算标准画幅比 (`1:1`、`16:9`、`9:16`、`4:3`、`3:4`)，提取主色相与 HEX 色盘。
- 🎯 **生图引擎指令一键生成**：
  - Midjourney / Niji 完整命令行 (`/imagine prompt: ... --ar ... --v 6.1`)
  - FLUX / SDXL / ComfyUI 正向与负向约束词 (Negative Prompt)
- 🗂️ **本地历史记录与导出**：自动保存反推记录，支持按关键词搜索、一键导出为 Markdown 笔记或 JSON 备份。
- 📚 **官方预设范例展厅**：内置 7 大类别的示范案例，一键载入即刻体验。
