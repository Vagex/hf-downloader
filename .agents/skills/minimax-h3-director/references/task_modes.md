# ComfyUI MiniMax-H3 Director 模式与参数手册

## 1. 任务模式 (task_type) 深度解析

### 1.1 `fl2v` (First-Last Frame to Video / 首尾帧生成)
- **UNET**: `fl2va`
- **特点**: 最适合长视频与复杂连续动作生成。
- **推荐搭配**: 开启「段间引导 (Motion Context)」，推荐上下文帧数为 `22` 帧。
- **工作机制**: Group 1 使用上传的首帧图片；从 Group 2 开始，勾选「引用上段」，自动抓取上一段末尾的 22 帧运动趋势注入当前段，实现完美的动作连续性。

### 1.2 `r2v` (Reference to Video / 素材组参考生成)
- **UNET**: `ref2va`
- **特点**: 适合多角色、固定道具、复杂场景一致性。
- **工作机制**: 节点支持挂载图片1–9、音频1–3、视频1–3。
- **提示词标签规范**:
  - `<Picture 1>` / `<Picture 2>`: 引用角色或道具外观。
  - `<Video 1>`: 引用动作节奏或背景。
  - `<Audio 1>`: 引用音频音轨。

### 1.3 `v2v` / `rv2v` (Video to Video / 视频转视频)
- **UNET**: `ref2va`
- **特点**: 实拍视频重绘、动作捕捉迁移。
- **工作机制**: 源视频自动绑定为 `<Video 1>`，`rv2v` 额外允许挂载参考图与参考音频。

## 2. 关键节点参数推荐

| 参数名称 | 推荐值 | 说明 |
| :--- | :--- | :--- |
| **CLIP Loader** | **`minimax` (Qwen3-VL)** | 必须选用 minimax 类型，确保强大的中英文多模态解析能力 |
| **段间引导 (Motion Context)** | **True (开启)** | 多段生成必须开启，避免每段之间动作重置或瞬移 |
| **上下文帧数 (Context Frames)** | **`22`** | 官方及社区推荐最佳平衡值（可选 5 / 22 / 39 / 56） |
| **FPS** | **`24` 或 `25`** | 电影标准帧率 |
| **二采/放大 (Refine)** | 可选接 `MiniMax H3 Director Refine` | 显存充裕时开启，做同分辨率精修或超分辨率放大 |
